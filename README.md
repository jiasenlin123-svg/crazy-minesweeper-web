# 疯狂扫雷｜Crazy Minesweeper

《疯狂系列》第 2 款：一款面向直播场景的“逻辑推理 + 风险管理 + 疯狂事件”扫雷游戏。

## 在线试玩

GitHub Pages 启用后，可直接在浏览器中游玩。

## 当前玩法

- 经典扫雷：首击 3×3 安全、揭格、插旗、0 格连锁展开
- 三档难度：轻松 / 正常 / 疯狂
- CHAOS 疯狂值与警报系统
- SAFE 连击与道具奖励
- 三种疯狂事件：地雷暴动 / 数字干扰 / 雷区过载
- 三种救命道具：冷静剂 / 雷达 / 防爆盾
- 直播控制台式 UI
